# 🛒 Ecommerce Sales Analytics Dashboard

## 📌 Project Overview

This project analyzes Ecommerce sales data using SQL and Power BI to uncover insights related to revenue, profitability, customer behavior, product performance, and regional trends.

The project follows a complete analytics workflow:

Raw Data → SQL Analysis → Data Transformation → Power BI Dashboard → Business Insights

---

## 🎯 Business Objectives

- Analyze sales performance across regions and categories
- Identify top customers and products
- Measure profitability and revenue trends
- Evaluate shipping and delivery performance
- Generate actionable business insights
